# Dicas do VSCode

## Atalhos no VSCode
- CTRL + ; Cria uma linha de comentário

## Configurações no VSCode
- Alterar tema: Arquivo / Preferências / Temas / Temas de cores
- Alterar ícone: Arquivo / Preferências / Temas / Temas de ícones de arquivos
- Abrir terminal: ... / Terminal / Novo terminal

# Comandos Python
- Print() - Mostra aguma informação na tela
- Input() - pede algo para o usuário

# Variaveis
- Nome, Valor(o valor que a variavel recebe), Tipo(str - string; int - numeros inteiros; float - numero com decimal; bool - true/false)
